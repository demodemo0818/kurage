# 🪼 Kurage v1.4.3

**v1.4.2 で起きていた、Android 版の画像ビューアを下スワイプで閉じられない問題を修正するリリースです。** Windows 版と Web 版の動作に変更はありません。

## 🛠 改善・修正

- **Android で、画像ビューアを下スワイプで閉じられない問題を修正**

  v1.4.2 から、Android 版で画像を全画面で開いたときに、下にスワイプしても画像が少し動くだけで閉じられなくなっていました。v1.4.2 での改善（ピンチ拡大が閉じる操作やページ送りに化けない・短い距離で閉じられる）はそのままに、下スワイプで閉じられるように戻しました。

## 入手方法

| プラットフォーム | 入手先 |
|---|---|
| Windows | このページ下の **Assets** からダウンロード |
| Android | [Google Play](https://play.google.com/store/apps/details?id=jp.demo2.kurage) |
| Web | https://kurage.demo2.jp |

### Windows 版について

- **インストーラー版**: `kurage-v1.4.3-setup.exe` — 実行するとユーザー単位でインストールされ、スタートメニューに登録されます (管理者権限不要)。
- **ポータブル版**: `kurage-v1.4.3-windows.zip` — 解凍して `kurage.exe` を実行するだけ。
- どちらも未署名のため、初回に「Windows によって PC が保護されました」と表示されたら「**詳細情報**」→「**実行**」で起動できます。

## English

**This release fixes an issue introduced in v1.4.2 where swiping down could not close the image viewer on Android.** There are no changes to how the Windows and Web versions behave.

### Improvements and fixes

- **Swiping down now closes the image viewer again on Android.** Since v1.4.2, swiping down on a full-screen image on Android only moved the image slightly instead of closing the viewer. Swipe-to-close works again, and the v1.4.2 improvements are kept: pinch-to-zoom no longer closes the viewer or switches images, and a shorter swipe is enough to close it.
