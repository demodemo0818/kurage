# 🪼 Kurage v1.2.3

**動画を保存すると JPG ファイルになってしまう問題と、ダークモードで「絵文字を選択」の見出しが読みにくい問題を修正しました。**

Windows / Android / Web すべてが対象の更新です。

## 🐛 修正

- **動画・音声を保存するとファイルの種類が JPG になる問題を修正** ([#5](https://github.com/demodemo0818/kurage/issues/5))

  タイムラインの動画を開いて「保存」すると、中身は動画のままファイル名だけが `.jpg` になり、そのままでは動画として開けない状態でした。保存するファイル名の拡張子が画像決め打ちになっていたことが原因です。

  今後は元のファイルの種類 (mp4 / mov / gif / png / mp3 など) に合わせた拡張子で保存されます。「保存先を毎回確認する」設定をオンにしている場合の保存ダイアログも、動画には動画の種類が表示されるようになりました。

- **ダークモードで「絵文字を選択」の見出しが暗くて読みにくい問題を修正** ([#6](https://github.com/demodemo0818/kurage/issues/6))

  新規投稿画面で絵文字ボタンを押したときに開く「絵文字を選択」の見出しが、ダークモード (システム設定に追従してダークになる場合を含む) で背景に沈んでほとんど見えなくなっていました。見出しの色に、ダークモードでは暗いグレーになってしまう色を使っていたことが原因です。

  あわせて、本文にメンションを入力したときに出る候補ボタンもダークモードで縁が見えづらかったため、同じ原因を直しました。

ご報告いただきありがとうございました。

- **インストーラー版**: `kurage-v1.2.3-setup.exe` — 実行するとユーザー単位でインストールされ、スタートメニューに登録されます (管理者権限不要)。

- どちらも未署名のため、初回に「Windows によって PC が保護されました」と表示されたら「**詳細情報**」→「**実行**」で起動できます。

## English

**Fixes videos being saved as JPG files, and an unreadable "Pick an emoji" heading in dark mode.** This update applies to Windows, Android and Web.

### Saved videos and audio kept a `.jpg` extension ([#5](https://github.com/demodemo0818/kurage/issues/5))

Saving a video from the media viewer produced a file whose contents were still a video but whose name ended in `.jpg`, so it would not open as a video. The save filename always used an image extension. Files are now saved with an extension matching the actual media type (mp4 / mov / gif / png / mp3 and so on), and the "ask where to save" dialog now offers the matching file type too.

### "Pick an emoji" heading was too dark to read in dark mode ([#6](https://github.com/demodemo0818/kurage/issues/6))

The heading of the emoji picker on the compose screen almost disappeared into the background in dark mode (including when following the system setting), because it used a colour that resolves to a very dark grey on dark themes. The mention suggestion chips had the same problem with their outlines and were fixed as well.

Thanks to everyone who reported these ([#5](https://github.com/demodemo0818/kurage/issues/5), [#6](https://github.com/demodemo0818/kurage/issues/6)).
