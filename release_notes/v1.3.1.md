# 🪼 Kurage v1.3.1

**不具合修正のリリースです。** Android で動画を添付するとアプリが落ちる問題、添付された音声を再生できない問題、Windows でマウスホイールが横スクロールしかしなくなる問題などを修正しました。あわせて、Mastodon 4.7.2 のサーバーで HEIC / HEIF / AVIF 画像を添付できなくなった問題にも対応しています。

## ✨ 改善

- **CW 付きの投稿に返信すると、CW を引き継ぐように**

  返信先の投稿に CW（内容の警告）が付いている場合、返信の CW 欄に同じ文言が最初から入るようになりました。Mastodon のウェブ版と同じ動作です。CW が不要な場合は、CW 欄を消してから投稿してください。

- **横スクロール表示の画像をマウスで送れるように（Web / Windows）**

  設定 → 外観設定 →「サムネイル表示」を「横スクロール」にしていると、スマホではスワイプで画像を送れますが、マウスでは送る方法がありませんでした。画像の上にカーソルを乗せると左右に矢印ボタンが出るようになり、クリックで送れます。

- **「ギャラリーから選択」で動画も選べるように（Android）**

  投稿画面の「ギャラリーから選択」で、画像だけでなく動画も選べるようになりました。

## 🐛 修正

- **動画を添付するとアプリが落ちる問題を修正（Android）** ([#9](https://github.com/demodemo0818/kurage/issues/9))

  投稿画面の「ファイルを選択」でサイズの大きな動画を選ぶと、アプリが終了してしまうことがありました。ファイル全体を一度にメモリへ読み込んでいたことが原因です。少しずつ読み込みながらアップロードするようにしました。

- **添付された音声を再生・保存できない問題を修正** ([#10](https://github.com/demodemo0818/kurage/issues/10))

  音声ファイルが添付された投稿で、音声が壊れた画像として表示され、再生できませんでした。音声用の表示にして、タップで再生できるようにしました。Android で音声を保存できなかった問題もあわせて修正しました（音声は「Music」フォルダに保存されます）。

- **マウスホイールが横スクロールしかしなくなる問題を修正（Windows）** ([#7](https://github.com/demodemo0818/kurage/issues/7))

  使っているうちに、縦のホイールをどこで回してもカラムが横にスクロールするようになり、アプリを再起動するまで直らないことがありました。v1.3.0 でも修正を入れましたが、原因の見立てが誤っていたため直っていませんでした。

  本当の原因は、Kurage が使っている UI フレームワーク Flutter の Windows 版の不具合でした。日本語入力の使用中などに、Shift キーが押されたままの状態で残ってしまうことがあります。マウスを動かしたときにこの状態を見つけて解除するようにしました。

- **Mastodon 4.7.2 のサーバーで HEIC / HEIF / AVIF 画像を添付できない問題に対応**

  Mastodon 4.7.2 から、サーバー側で HEIC / HEIF / AVIF 形式の画像を受け付けなくなりました（iPhone で撮った写真などが該当します）。Kurage がアップロード前に JPEG へ変換するようにしました。4.7.1 以前のサーバーでもサーバー側で JPEG に変換していたので、投稿される画像はこれまでと変わりません。

  Windows 版と、ブラウザが HEIC / HEIF に対応していない場合の Web 版（Chrome など）では変換ができないため、添付できない旨のメッセージが出ます。JPEG や PNG に変換してから添付してください。

- **引用された投稿の画像が、閲覧注意でもぼかされずに表示される問題を修正**

  引用元の投稿に CW や閲覧注意（NSFW）の指定があっても、引用カードの中では画像がぼかされずに表示されることがありました。通常の投稿と同じく画像を 1 枚ずつぼかし、タップするとその画像だけ表示されるようにしました。設定 → 外観設定 →「メディアのぼかしを常に解除」をオンにしている場合は、これまでどおりぼかしません。

- **表示名の一部の文字が □ になる問題を修正** ([#11](https://github.com/demodemo0818/kurage/issues/11))

  「ᤖﾞ」のように、特殊な文字に半角の濁点・半濁点を組み合わせた表示名で、両方の文字が □ で表示されていました。正しく表示されるようにしました。

- **端末の言語を切り替えても表示言語が変わらない問題を修正**

  設定 → 外観設定 →「表示言語」が「システム設定に従う」（初期設定）のとき、アプリを起動したまま端末の言語を変えても、アプリを再起動するまで元の言語のままでした。すぐに切り替わるようにしました。

- **まれにアプリが落ちる問題をいくつか修正**

  サーバーのエラーや通信の切断があったときにプロフィール画面で落ちる、すべてのアカウントからログアウトした直後に落ちる、画像のアップロード中に投稿画面を閉じると落ちる、などの問題を修正しました。

## English

**This is a bug-fix release.** It fixes a crash when attaching videos on Android, audio attachments that could not be played, and the mouse wheel getting stuck scrolling sideways on Windows. It also works around Mastodon 4.7.2 no longer accepting HEIC / HEIF / AVIF images.

### Improvements

- **Replies to posts with a content warning now keep the CW.** When you reply to a post that has a content warning, the CW field of your reply is prefilled with the same text, just like the Mastodon web UI. Clear the field before posting if you don't want it.
- **Scroll horizontal thumbnails with the mouse (Web / Windows).** With Settings → Appearance → "Thumbnail layout" set to "Horizontal scroll", you could swipe through images on a phone but had no way to do so with a mouse. Hovering over the images now shows left / right arrow buttons.
- **"Choose from the gallery" now includes videos (Android).**

### Fixes

- **Attaching a video crashed the app (Android)** ([#9](https://github.com/demodemo0818/kurage/issues/9)). Picking a large video with "Choose a file" could close the app, because the whole file was read into memory at once. Videos are now read and uploaded in chunks.
- **Audio attachments could not be played or saved** ([#10](https://github.com/demodemo0818/kurage/issues/10)). Audio showed up as a broken image. It now appears as an audio item you can tap to play. Saving audio on Android also works now (saved to the "Music" folder).
- **The mouse wheel only scrolled sideways (Windows)** ([#7](https://github.com/demodemo0818/kurage/issues/7)). After a while, the vertical wheel could start scrolling the columns sideways everywhere until the app was restarted. The fix in v1.3.0 was based on a wrong diagnosis and did not solve it. The real cause is a bug in the Windows version of Flutter, the UI framework Kurage uses: the Shift key can be left in a "pressed" state, for example while using an input method. Kurage now detects and clears that state when the mouse moves.
- **HEIC / HEIF / AVIF images could not be attached on Mastodon 4.7.2 servers.** Mastodon 4.7.2 stopped accepting these formats (for example, photos taken on an iPhone). Kurage now converts them to JPEG before uploading. Older servers already converted them to JPEG on their side, so posted images look the same as before. The Windows version, and the Web version in browsers that cannot read HEIC / HEIF (such as Chrome), cannot convert them and show a message instead; please convert the image to JPEG or PNG first.
- **Images in quoted posts were shown unblurred even when marked sensitive.** Images inside a quote are now blurred one by one, like in regular posts, and tapping one reveals only that image. If Settings → Appearance → "Always unblur media" is on, they are not blurred, as before.
- **Some characters in display names appeared as boxes** ([#11](https://github.com/demodemo0818/kurage/issues/11)). Display names that combine an uncommon character with a half-width voiced sound mark, such as "ᤖﾞ", now render correctly.
- **The display language did not follow a system language change.** With "Display language" set to "Follow system setting" (the default), changing the device language while the app was running had no effect until restart. It now switches right away.
- **Fixed several rare crashes**, including on the profile screen after a server error or connection loss, right after logging out of every account, and when closing the composer during an image upload.

### Other

- Updated the Android build toolchain (Android Gradle Plugin and related tools).
