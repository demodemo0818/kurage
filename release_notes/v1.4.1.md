# 🪼 Kurage v1.4.1

**Web 版の不具合修正のリリースです。** 投稿画面で日本語を変換している途中に、入力し終える前に投稿されてしまうことがある問題を修正しました。

## 🐛 修正

- **変換中に Tab → Enter と打つと、入力途中で投稿されてしまう問題を修正（Web）**

  日本語を入力中、Tab キーで予測候補を出して Enter で確定すると、本文を書き終える前にそのまま投稿されていました。変換中の Tab で入力欄から投稿ボタンにフォーカスが移ってしまい、確定の Enter が投稿ボタンを押したことになっていたのが原因です。変換中の Tab ではフォーカスが移らないようにしました。予測候補はこれまでどおり Tab で表示できます。

- **インストーラー版**: `kurage-v1.4.1-setup.exe` — 実行するとユーザー単位でインストールされ、スタートメニューに登録されます (管理者権限不要)。
- **ポータブル版**: `kurage-v1.4.1-windows.zip` — 解凍して `kurage.exe` を実行するだけ。
- どちらも未署名のため、初回に「Windows によって PC が保護されました」と表示されたら「**詳細情報**」→「**実行**」で起動できます。

## English

**This is a bug-fix release for the web version.** It fixes posts sometimes being sent while you were still typing with an input method (IME).

### Fixes

- **Pressing Tab and then Enter during IME composition sent the post before you finished (Web).** When typing Japanese, showing the predictive candidates with Tab and confirming one with Enter sent the post right away. Tab during composition moved the focus from the text field to the post button, so the Enter that confirmed the candidate pressed the post button. Tab during composition no longer moves the focus, and it still shows the predictive candidates as before.
