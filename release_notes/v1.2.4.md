# 🪼 Kurage v1.2.4

**ボスキー（偽装モード）で返信するときに、ヘッダーのロゴと右側のボタンが上にずれる問題を修正しました。**

ボスキーは Web / デスクトップ限定の機能のため、今回の変更は Windows / Web が対象です（Android 版に見た目や動作の変更はありません）。

## 🐛 修正

- **ボスキー（偽装モード）で返信中にヘッダーの表示がずれる問題を修正** ([#8](https://github.com/demodemo0818/kurage/issues/8))

  ボスキー（設定 →「ボスキー（偽装モード）」→「ボスキーを有効にする」、F9 で切り替え）で表示中の画面から投稿に返信すると、入力欄の上に出る「返信先」のラベルのぶんだけ、左のロゴと右側の更新ボタン・アカウントアイコンが本来の位置より上にずれていました。

  「返信先」のラベルを入力欄の上の独立した行に分け、返信中でもロゴと右側のボタンが入力欄の中心に揃うようにしました。なお、返信中はラベルのぶんヘッダー全体が高くなり、下のタブがその分下がりますが、こちらは意図した表示です。

ご報告いただきありがとうございました。

### Windows 版について

- **インストーラー版**: `kurage-v1.2.4-setup.exe` — 実行するとユーザー単位でインストールされ、スタートメニューに登録されます (管理者権限不要)。
- **ポータブル版**: `kurage-v1.2.4-windows.zip` — 解凍して `kurage.exe` を実行するだけ。
- どちらも未署名のため、初回に「Windows によって PC が保護されました」と表示されたら「**詳細情報**」→「**実行**」で起動できます。

## English

**Fixes the header drifting out of alignment while replying in boss key (disguise) mode.** The boss key is a Web / desktop-only feature, so this update applies to Windows and Web (nothing changes for Android).

### Header drifted while replying in boss key (disguise) mode ([#8](https://github.com/demodemo0818/kurage/issues/8))

While the disguise was showing (Settings → "Boss key (disguise mode)" → "Enable the boss key", toggled with F9), replying to a post put a "Replying to" label above the input box, and the logo on the left along with the refresh and account buttons on the right drifted upwards with it.

The label now sits on its own row above the input box, so the logo and the buttons stay centred on the input while you reply. The header itself still grows taller by the height of the label, and the tabs below shift down accordingly — that part is intended.

Thanks to everyone who reported this ([#8](https://github.com/demodemo0818/kurage/issues/8)).
