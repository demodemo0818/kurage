# 🪼 Kurage v1.3.0

**プロフィールのフォロー中・フォロワー一覧から、そのままフォロー／フォロー解除できるようになりました。** あわせて、Android で「共有」から投稿したあと次回起動時に投稿画面が出てしまう問題と、デッキ表示でマウスホイールが横に効いてしまう問題を修正しています。

## ✨ 新機能・変更

- **フォロー中／フォロワー一覧の各行にフォローボタンを追加**

  プロフィール →「フォロー」「フォロワー」タブの各行に、フォロー／フォロー解除のボタンが出るようになりました。相手のプロフィールを開かなくても、一覧から直接フォローの操作ができます。自分のプロフィールだけでなく、他の人のプロフィールのフォロー中／フォロワー一覧でも使えます。

  非公開（鍵）アカウントにフォローを申請した場合は、承認されるまでボタンが「リクエスト中」の表示になります。もう一度押すと申請を取り消せます。

- **「フォロワーから外す」を ⋯ メニューに移動**

  これまで自分のプロフィールのフォロワー一覧では、各行の右端が「フォロワーから外す」ボタンになっていました。誤って押しやすい位置だったため、Mastodon のウェブ版と同じく、右端はフォローボタンにして、「フォロワーから外す」は各行の **⋯ メニュー**の中に移しました。操作そのもの（確認ダイアログを含む）はこれまでと同じです。

## 🐛 修正

- **共有から投稿したあと、次回起動時に投稿画面が再び開く問題を修正（Android）**

  ブラウザなどの「共有」から Kurage に送って投稿を完了しても、次にアプリを起動したときに、投稿済みの内容が入った投稿画面がもう一度開いてしまうことがありました。共有で受け取った内容を Android 側が保持し続け、アプリの再起動時に再び渡していたことが原因です。共有の受け取りを専用の入口に分けて、内容が残らないようにしました。

  下書きの保存・復元の動作には変更ありません。

- **デッキ表示でカラムの下端にカーソルがあるとホイールが横に効く問題を修正（Windows / Web）** ([#7](https://github.com/demodemo0818/kurage/issues/7))

  横に並べたカラムの下端付近にマウスカーソルがあるとき、ホイールを回してもタイムラインが縦にスクロールせず、カラム全体が横に動いてしまうことがありました。常に表示している横スクロールバーがタイムラインの上に重なっていたためです。バーのぶんカラムを短くして重ならないようにしました。

### Windows 版について

- **インストーラー版**: `kurage-v1.3.0-setup.exe` — 実行するとユーザー単位でインストールされ、スタートメニューに登録されます (管理者権限不要)。
- **ポータブル版**: `kurage-v1.3.0-windows.zip` — 解凍して `kurage.exe` を実行するだけ。
- どちらも未署名のため、初回に「Windows によって PC が保護されました」と表示されたら「**詳細情報**」→「**実行**」で起動できます。

## English

**You can now follow and unfollow directly from the following / followers lists on a profile.** This release also fixes a share-to-post issue on Android and a mouse wheel issue in the deck layout.

### Follow buttons in the following / followers lists

Each row in the "Following" and "Followers" tabs of a profile now has a follow / unfollow button, so you no longer have to open the other person's profile first. It works on your own profile as well as on anyone else's.

If you request to follow a locked account, the button shows "Requested" until the request is approved. Pressing it again cancels the request.

### "Remove from followers" moved into the ⋯ menu

The right-hand side of each row in your own followers list used to be a "Remove from followers" button, which was easy to hit by accident. As on the Mastodon web UI, that spot is now the follow button, and "Remove from followers" lives in the **⋯ menu** on each row. The action itself, including its confirmation dialog, is unchanged.

### Share-to-post reopened the composer on the next launch (Android)

After sharing a page to Kurage from a browser and posting it, launching the app again could reopen the composer with the text you had already posted. Android was holding on to the shared content and handing it back when the app restarted. Sharing is now received through a dedicated entry point so nothing is left behind.

Draft saving and restoring is unaffected.

### The mouse wheel scrolled sideways at the bottom of a column (Windows / Web) ([#7](https://github.com/demodemo0818/kurage/issues/7))

With the cursor near the bottom of a column in the deck layout, the wheel moved the columns sideways instead of scrolling the timeline, because the always-visible horizontal scrollbar overlapped the timeline. Columns are now shortened by the height of the bar so the two no longer overlap.
