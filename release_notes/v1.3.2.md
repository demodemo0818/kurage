# 🪼 Kurage v1.3.2

**不具合修正のリリースです。** Android の 3 ボタンナビゲーションで、ダークモードでも画面下のナビゲーションバーが白っぽく表示される問題と、ハッシュタグではないリンクがハッシュタグとして表示される問題を修正しました。

## 🐛 修正

- **ダークモードでも画面下のナビゲーションバーが白っぽくなる問題を修正（Android）**

  3 ボタンナビゲーション（戻る・ホーム・履歴のボタン）を使っている一部の端末（Xiaomi の HyperOS など）で、ダークモードにしていても画面下のボタンの帯が白っぽい色で表示されていました。Android 15 以降、OS がこの帯に半透明の膜を重ねるようになり、その色がアプリの外観設定に従わないことが原因です。膜を重ねないようにして、アプリのテーマと同じ色で表示されるようにしました。ジェスチャーナビゲーションを使っている場合は、もともとこの問題は起きません。

- **普通のリンクがハッシュタグとして表示される問題を修正**

  URL の途中に `/tag/` や `/tags/` を含むリンク（GitHub のリリースページ `…/releases/tag/v1.3.1` や、ブログのタグ一覧ページなど）が、ハッシュタグとして表示されていました。タップしてもリンク先が開かず、ハッシュタグのタイムラインに移動していました。Mastodon のウェブ版と同じく、本当のハッシュタグだけをハッシュタグとして扱うようにしました。

## English

**This is a bug-fix release.** It fixes the navigation bar looking whitish in dark mode with 3-button navigation on Android, and ordinary links being shown as hashtags.

### Fixes

- **The navigation bar looked whitish even in dark mode (Android).** On some devices using 3-button navigation (Back / Home / Recents), such as Xiaomi phones running HyperOS, the button area at the bottom of the screen was drawn in a whitish color even in dark mode. Since Android 15, the system draws a translucent scrim over this area, and its color does not follow the app's appearance. Kurage now turns the scrim off so the area matches the app's theme. Gesture navigation was not affected.
- **Ordinary links were shown as hashtags.** Links whose URL contained `/tag/` or `/tags/` somewhere in the path (for example a GitHub release page such as `…/releases/tag/v1.3.1`, or a blog's tag page) were shown as hashtags, and tapping them opened a hashtag timeline instead of the link. Only real hashtags are now treated as hashtags, as in the Mastodon web UI.
