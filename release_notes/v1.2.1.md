# 🪼 Kurage v1.2.1

**Windows 版で動画を再生するとアプリが終了してしまう問題を修正しました。**

この更新は **Windows 版のみが対象**です。Android / Web 版はこの問題の影響を受けないため、これまで通り v1.2.0 のままご利用いただけます。

## 🐛 修正

- **Windows: 動画を再生するとアプリがクラッシュする問題を修正** ([#1](https://github.com/demodemo0818/kurage/issues/1))

  v1.2.0 で追加した Windows 版の動画再生機能が、配布パッケージでは動作していませんでした。原因は、配布用の zip / インストーラーに、アプリのビルドに使ったものより**古いバージョンの VC++ ランタイム**が同梱されていたことです。アプリの起動そのものはできるため気付きにくく、動画の再生を開始した時点でアプリが終了していました。パッケージ生成の手順を修正し、常に正しいバージョンが同梱されるようにしました。

  アプリ本体のコードに変更はありません。

ご報告いただきありがとうございました。

### Windows 版について

- **インストーラー版**: `kurage-v1.2.1-setup.exe` — 実行するとユーザー単位でインストールされ、スタートメニューに登録されます (管理者権限不要)。
- **ポータブル版**: `kurage-v1.2.1-windows.zip` — 解凍して `kurage.exe` を実行するだけ。
- どちらも未署名のため、初回に「Windows によって PC が保護されました」と表示されたら「**詳細情報**」→「**実行**」で起動できます。

## English

**Fixes a crash when playing videos on Windows.** This update targets **Windows only** — Android and Web are unaffected and can stay on v1.2.0.

The video playback added in v1.2.0 never worked in the distributed Windows build: the release package bundled an **older VC++ runtime than the one the app was built with**. The app started up normally, which made the problem hard to spot, but it terminated as soon as video playback began. The packaging step has been fixed so that a matching runtime is always bundled. No application code was changed.

Thanks to everyone who reported this ([#1](https://github.com/demodemo0818/kurage/issues/1)).
